## Preparando o ambiente (VS Code)

1. **Instale o Python** em https://www.python.org/downloads/
   - No Windows, marque **"Add python.exe to PATH"** na primeira tela do instalador.
   - Teste no terminal: `python --version`
2. **Instale o VS Code** em https://code.visualstudio.com/
3. No VS Code, abra a aba **Extensões** (Ctrl+Shift+X) e instale:
   - **Python** (Microsoft) – já instala o Pylance e o Python Debugger
4. Abra esta pasta no VS Code: **Arquivo > Abrir Pasta…**
5. Abra um arquivo `.py` e clique em **▶ Run Python File** (canto superior direito).
   - Se pedir, escolha o interpretador Python instalado (Ctrl+Shift+P > "Python: Select Interpreter").
