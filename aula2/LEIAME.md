# Aula 2 – Estruturas de decisão (IF)

Curso: Analista de Dados – Big Data Science (13455) · Senac RJ

## Como rodar

- No VS Code: abra o arquivo e clique em **▶ Run Python File**.
- No terminal, dentro desta pasta: `python nome_do_arquivo.py` (ou `py nome_do_arquivo.py`).

| Arquivo | Para quê |
|---|---|
| `01_comparacao.py` | Operadores de comparação, `=` x `==`, comparar textos |

| `03_elif.py` | Vários caminhos com `elif` (semáforo, faixa etária) |

| `05_pratica_assistida.py` | Prática assistida: cinema, frete grátis, divisão segura |
